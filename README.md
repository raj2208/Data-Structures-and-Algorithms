# Data Structures and Algorithms

A personal repository for DSA interview preparation.

## Why this exists

When you practice 200–500 DSA problems, you stop remembering the ones you did early on. This repository solves that — every problem I solve gets stored here along with its approach and solution, so I can come back and revise quickly instead of re-solving from scratch.

## What's inside

- **Concept notes** for each topic — the theory you need before touching problems
- **Problems** organized by topic — problem statement, approach, and solution in separate files
- Each topic lives in its own folder so everything is easy to find

## How I use it

I learn concepts from AI, then solve problems, then commit everything here in a structured way. Keeping it organized means revision takes minutes instead of hours.

The GitHub contribution graph keeps me consistent.
